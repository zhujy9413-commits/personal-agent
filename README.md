# Personal Agent

个人项目助手：长期记住项目与偏好，帮助排优先级、拆小动作、查资料、整理文档和适时跟进。第一版已确认加入微信双向对话，以及在明确授权范围内补齐、验证和复用新能力。

**当前状态：等待材料。** 收到用户材料后，先阅读并核对现有决定，再按已有授权开始制作。当前没有可运行的独立 agent，未接入微信，也未启动实际资讯推送或定时任务。

## 飞书目录

现有成果及后续产生的项目文档，按实际文档类型写入用户指定的 [Personal Agent飞书目录](https://my.feishu.cn/wiki/Zsu4wg4ijizVMdkGo11cYlERnkg)，分为独立子文档。具体同步结果见 `document-sync.json`。

当前没有独立完整PRD；总验收文档不冒充详细PRD。后续产出PRD等成果时再分别补入，并维护目录。

## 版本与资料边界

- 已采用的决定、方案建议、纸面演练和实际验证结果分别记录。
- 当前基线支持微信双向对话；早期单向接收的记录作为历史保留。
- 未来原始材料不自动加入仓库；资料按用户指定范围处理，“仅这次使用”内容不转为长期项目记忆。
- 密钥、凭据、本地运行配置及未经授权的原始私有资料不随文档提交。
- 后续实施按有意义的进展提交；第一版可用后再标记相应版本。
