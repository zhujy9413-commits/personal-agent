# Personal Agent

个人项目助手：长期记住项目与偏好，帮助排优先级、拆小动作、查资料、整理文档和适时跟进。第一版已确认用QQ作为双向对话与推送入口，微信暂不实施；同时在明确授权范围内补齐、验证和复用新能力。

**当前状态（2026年10月31日）：材料已收到，独立QQ机器人部署进行中。** 部署包已阅读、校验并解压；阿里云杭州2核4GiB、40GiB系统盘、Ubuntu 22.04试用实例已创建并显示运行中。云端后台及私有管理通道已运行，独立DeepSeek Flash实际请求测试通过，固定插件已安装；QQ扫码及真实私聊、长期记忆、表情和头像验收仍待完成。多项目协作、资讯推送及额度提醒均未接通。此部署不代表personal agent全部能力已实现。

**已确认的服务器额度提醒：** 预计剩余可用时间降至72小时以内、24小时以内时各提醒一次，由用户决定停止或续费。不自动释放实例或删除数据；单纯关机不保证停止磁盘等资源计费。计算与验收规则见总验收文档“服务器免费额度提醒”。

## 版本与资料边界

- 已采用的决定、方案建议、纸面演练和实际验证结果分别记录。
- 当前基线以QQ统一承接聊天、项目协作、早报和提醒，微信暂不实施；早期微信方案和纸面测试保留为历史。
- 未来原始材料不自动加入仓库；资料按用户指定范围处理，“仅这次使用”内容不转为长期项目记忆。
- 密钥、凭据、本地运行配置及未经授权的原始私有资料不随文档提交。
- 后续实施按有意义的进展提交；第一版可用后再标记相应版本。
